# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Description
This project provides a command-line calculator for computing simple interest 
given the principal amount, interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Usage
Run the script `simple-interest.sh` and enter the requested values when prompted:
- Principal amount
- Interest rate (%)
- Time period (years)
